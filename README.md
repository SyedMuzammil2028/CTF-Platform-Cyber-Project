Death Note CTF - Training Platform

Death Note CTF is a Capture The Flag (CTF) cybersecurity training platform designed to provide hands-on, practical experience across multiple security domains. The project focuses on bridging the gap between theoretical cybersecurity education and real-world attack simulation through a structured and gamified learning environment.

- Challenge Domains

  - Cryptography: Caesar, XOR, Vigenère, Playfair, hashing challenges, RSA mini-tasks, and Wiener’s RSA attack
  - OSINT: Metadata extraction, social media reconnaissance, hidden information and image discovery
  - Web Security: SQL Injection (Union-based and Blind), Reflected and Stored XSS, IDOR, LFI, directory enumeration, weak credential attacks
  - Digital Forensics: LSB steganography, PCAP analysis, deleted file recovery, string extraction, PDF redaction, DNS analysis
  - Special Challenges: Wi-Fi handshake analysis, tone dialing, spectrogram-based data extraction

- Platform Features

  - Gamified scoring and progress tracking system
  - Optional hints and post-challenge writeups
  - Beginner-friendly design with progressive difficulty
  - Realistic attack and defense simulation scenarios

- Technical Stack

  - Backend: Python, Flask
  - Frontend: HTML, CSS, JavaScript
  - Database: SQL
  - Security Tools: Burp Suite, SQLmap, Hydra, Hashcat, OpenSSL
  - Forensics and OSINT Tools: Wireshark, Steghide, Binwalk, ExifTool, Sherlock
  - Platform: Linux (Kali), Flask-based local web interface

- Learning Outcomes

  - Practical exposure to penetration testing methodologies
  - Strong understanding of web security vulnerabilities and exploitation
  - Hands-on experience with cryptography, OSINT, and digital forensics
  - Improved analytical thinking and problem-solving skills
