# Death Note CTF – Ctf Practice Platform

Death Note CTF is a Capture The Flag (CTF) cybersecurity training platform designed to provide **hands-on, practical experience** across multiple security domains. The project bridges the gap between theoretical cybersecurity education and real-world attack simulation through a structured and gamified learning environment.

---

## Challenge Domains

- **Cryptography:** Caesar, XOR, Vigenère, Playfair, hashing challenges, RSA mini-tasks, Wiener’s RSA attack  
- **OSINT:** Metadata extraction, social media reconnaissance, hidden information and image discovery  
- **Web Security:** SQL Injection (Union-based & Blind), Reflected and Stored XSS, IDOR, LFI, directory enumeration, weak credential attacks  
- **Digital Forensics:** LSB steganography, PCAP analysis, deleted file recovery, string extraction, PDF redaction, DNS analysis  
- **Special Challenges:** Wi-Fi handshake analysis, tone dialing, spectrogram-based data extraction  

---

## Platform Features

- Gamified scoring and progress tracking system  
- Optional hints and post-challenge writeups  
- Beginner-friendly design with progressive difficulty  
- Realistic attack and defense simulation scenarios  

---

## Technical Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** SQL  
- **Security Tools:** Burp Suite, SQLmap, Hydra, Hashcat, OpenSSL  
- **Forensics & OSINT Tools:** Wireshark, Steghide, Binwalk, ExifTool, Sherlock  
- **Platform:** Linux (Kali), Flask-based local web interface

## How to Run

1. Clone the repository:  
   ```bash
   git clone https://github.com/SyedMuzammil2028/CTF-Platform-Cyber-Project.git
   ```
   
2. Navigate to the project directory:
  ```bash
  cd CTF-Platform-Cyber-Project
  ```

3. Install required Python packages (Flask, etc.):
  ```bash
  pip install -r requirements.txt
  ```

4. Run the Flask application:
  ```bash
  python app.py
  ```

5. Open your browser and go to http://localhost:5000 to access the platform.
